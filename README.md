# Sales Forecasting Project (Codec Technologies Internship)

## Objective
Predict future Walmart weekly sales using Machine Learning.

## Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest Regressor

## Project Workflow
1. Load Dataset
2. Data Cleaning
3. Feature Engineering (Year, Month, Week)
4. Exploratory Data Analysis (EDA)
5. Train Random Forest Model
6. Predict Weekly Sales
7. Evaluate using MAE, RMSE, and R² Score
8. Forecast Future Sales
